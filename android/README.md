# Nice 视频 · Android

[下载 NiceVideos.apk](./NiceVideos.apk)

Android 8.0（API 26）及以上的手机和平板可以安装本目录的测试版 APK。1.2.1（版本号 4）使用 AndroidX Media3 ExoPlayer、设备解码器和 OpenGL ES 2.0。应用名称为「Nice 视频 VR 1.2」。1.2.1 和 1.2.0 使用同一包名 `com.anxiong.nicevideos.vr.preview`。从 1.2.0 升级请先阅读下面的历史视频说明。安装 APK 或用 Android Studio 打开本目录均可，无需运行 iOS 工程。

## 安装试用

将 `NiceVideos.apk` 传到设备，在系统文件管理器中点开安装。如果系统询问是否允许本次来源安装应用，可给打开 APK 的文件管理器授权。已连接 USB 调试的 Mac 也可在仓库根目录执行：

```sh
adb install -r android/NiceVideos.apk
```

### 从 1.2.0 升级并保留历史视频

同一证书签名的自建版本可直接覆盖安装。仓库分发的 APK 由 CI 使用临时调试证书签名，不同构建可能需要更换安装。遇到 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 或「签名不一致」，保留旧应用，先备份视频。卸载会清理旧版专属目录。

从仓库的 1.2.0 调试包换到不同签名的 1.2.1 时，可以用 Mac、Python 3.8+ 和 Android 平台工具中的 `adb` 保留离线影片、收藏、服务器配置和续播进度。连接平板并授权 USB 调试，在旧版中等下载结束或取消未完成的下载。用以下命令将副本备份到 Mac 上空间充足的新文件夹。示例命令在仓库根目录运行。

```sh
python3 android/tools/legacy_download_backup.py backup "$HOME/NiceVideos-1.2-backup"
```

看到 `Verified backup complete` 后，核对影片数量和备份中的 `manifest.json`。有下载记录却显示 0 个文件时，请保留旧安装并检查当前设备和用户。确认备份完整后，可在设备上卸载旧版、安装此版，再运行下面的命令。请在恢复完成后再添加新影片。

```sh
python3 android/tools/legacy_download_backup.py restore "$HOME/NiceVideos-1.2-backup"
```

看到 `Verified restore complete` 后打开 App 的「本地」。旧版中通过「打开文件」选过的外部影片仍在原处；更换安装后，Android 可能需要重新授权那些文件。请保留 Mac 上的备份直到在文件管理器和 App 内确认影片可播放。

### 下载位置与历史迁移

新下载保存在内部存储的 `Download/NiceVideos/`。可用文件管理器按片名查找，同名文件会使用新的文件名。Android 8、9 首次向公共目录写入时需要授予存储权限。

「本地」会自动逐个迁移已完成的旧版下载，保留片库编号、收藏及续播位置。覆盖升级时仍在传输的任务可在完成后迁移，失败任务再次下载时使用公共目录。迁移会先核对公共副本，再清理旧文件。设备不支持直接链接时，需要为当前影片留出复制空间。中断后可重新打开 App 继续，或点「本地 → 迁移历史下载」重试。

在已下载影片右侧菜单中，「从列表移除」保留公共文件，「删除本机副本」会删除公共文件。

## 播放

- 在首页点「打开文件」，用 Android 系统文件选择器选视频。播放器直接使用提供方交给它的 URI，无需将手机或平板上已有的视频导入片库。网盘提供方可能会先下载或缓存文件。拖动进度需要提供方支持随机读取。
- 打开影片后先显示原始画面，点底部「VR」进入。首次默认按 180° 全景、左右分屏、单屏观看处理，适合在平板上直接拖动环顾。点「VR 设置」按原片指定投影、片源排布和观看方式，设置按文件保留。
- 左右两幅为经纬全景图时选「180° 全景」或「360° 全景」；左右各有一个圆形鱼眼图像时可试「180° 鱼眼」（等距圆形，图像居中）；普通左右 3D 影片选「平面影院」里的半宽／全宽 SBS。全景同时支持单画面、左右和上下排布。180° 片源在后半球没有影像。
- 平板直接看选「单屏观看」，横放进手机眼镜选「双眼眼镜」。全景下单指拖动环顾、双指缩放、默认双击或点「回正」恢复正面。在「VR 设置」可以把「画面双击」改为播放／暂停、显示／隐藏控件，或把「双指缩放幅度」设为精细、标准或快速。这些手势偏好对各部影片生效。陀螺仪跟随可手动打开，依赖设备旋转传感器。切换观看方式和投影沿用同一播放进度和解码器。
- 高分辨率屏幕进入 VR 时默认用「流畅（最长边 1920）」绘制最终画面，保持屏幕比例。需要看清细节时可在「VR 设置 → VR 渲染清晰度」切换「屏幕原生」。该选项只控制 VR 画面绘制，播放器继续直接读取和解码原文件。
- 在 VR 播放画面中，Android 手柄 A 键切换播放／暂停，X 键回正全景视角，Y 键显示／隐藏控件，L1 后退 15 秒，R1 快进 15 秒。音量键保留系统行为。
- 拖动画面时可继续听当前声音。拖动底部进度条会预览时间，松开时跳一次，系统取消手势时继续原位置。需要排查断音时，可查看「片源信息」里的本次音频缓冲耗尽次数。
- 「片源信息」显示可读取的分辨率、编码、帧率和解码器名称。播放时，如果进度和实际时间均已走过 10 秒而显示端没有收到新画面，播放器会提示检查解码。遇到有声无图或解码失败，可在「片源信息」尝试设备提供的软件解码。设备缺少适用的软件解码器时，点「恢复自动解码」即可回到原进度。原文件的码率、分辨率和帧率决定解码负载。播放器支持超过 4 GiB 的文件偏移。
- 本地列表可按收藏或已下载筛选。文件菜单可以收藏影片、移除最近记录或删除已下载副本。
- 服务器页可填写本仓库 `videos/` 服务的地址，例如 `http://192.168.1.20:8106`，从列表下载到本机后离线播放。连接同一 Wi-Fi 时填服务器的局域网 IP。

## 自行构建

使用 JDK 17、Android SDK Platform 35 及 Build Tools 35.0.0。Gradle Wrapper 位于本目录。

```sh
cd android
./gradlew :app:assembleDebug
```

输出为 `app/build/outputs/apk/debug/app-debug.apk`。运行设备测试另需 FFmpeg、Python 3 和一台 Android 设备或模拟器。测试资源由 Gradle 生成，只放入测试包。

```sh
./gradlew :app:connectedDebugAndroidTest
```
