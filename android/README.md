# Nice 视频 · Android

[下载 NiceVideos.apk](./NiceVideos.apk)

Android 8.0（API 26）及以上的手机和平板可以安装本目录的测试版 APK。1.1.0 使用 AndroidX Media3 ExoPlayer、设备解码器和 OpenGL ES 2.0。应用名称为「Nice 视频 VR」，试用安装包使用独立包名，可与 1.0.0「Nice 视频」同时安装。首次使用请重新选择本地文件或填写服务器地址。安装 APK 或用 Android Studio 打开本目录均可，无需运行 iOS 工程。

## 安装试用

将 `NiceVideos.apk` 传到设备，在系统文件管理器中点开安装。如果系统询问是否允许本次来源安装应用，可给打开 APK 的文件管理器授权。已连接 USB 调试的 Mac 也可在仓库根目录执行：

```sh
adb install -r android/NiceVideos.apk
```

这是用于侧载试用的 debug 签名包。覆盖更新需要使用相同的签名证书。

## 播放

- 在首页点「打开文件」，用 Android 系统文件选择器选视频。播放器直接使用提供方交给它的 URI，无需将手机或平板上已有的视频导入片库。网盘提供方可能会先下载或缓存文件。拖动进度需要提供方支持随机读取。
- 打开影片后先显示原始画面，点底部「VR」进入。首次默认按 180° 全景、左右分屏、单屏观看处理，适合在平板上直接拖动环顾。点「VR 设置」按原片指定投影、片源排布和观看方式，设置按文件保留。
- 左右两幅为经纬全景图时选「180° 全景」或「360° 全景」；左右各有一个圆形鱼眼图像时可试「180° 鱼眼」（等距圆形，图像居中）；普通左右 3D 影片选「平面影院」里的半宽／全宽 SBS。全景同时支持单画面、左右和上下排布。180° 片源在后半球没有影像。
- 平板直接看选「单屏观看」，横放进手机眼镜选「双眼眼镜」。全景下单指拖动环顾、双指缩放、双击或点「回正」恢复正面。陀螺仪跟随可手动打开，依赖设备旋转传感器。切换观看方式和投影沿用同一播放进度和解码器。
- 「片源信息」显示可读取的分辨率、编码、帧率和解码器名称。遇到有声无图或解码失败可尝试设备提供的软件解码，再按需恢复自动选择。原文件的码率、分辨率和帧率决定解码负载。播放器支持超过 4 GiB 的文件偏移。
- 本地列表可按收藏或已下载筛选。文件菜单可以收藏影片、移除最近记录或删除已下载副本。
- 服务器页可填写本仓库 `videos/` 服务的地址，例如 `http://192.168.1.20:8106`，从列表下载到本机后离线播放。连接同一 Wi-Fi 时填服务器的局域网 IP。

## 自行构建

使用 JDK 17、Android SDK Platform 35 及 Build Tools 35.0.0。Gradle Wrapper 位于本目录。

```sh
cd android
./gradlew :app:assembleDebug
```

输出为 `app/build/outputs/apk/debug/app-debug.apk`。运行设备测试另需 FFmpeg、Python 3 和一台 Android 设备或模拟器。测试资源由 Gradle 生成，只放入测试包。

```sh
./gradlew :app:connectedDebugAndroidTest
```
