# Nice 视频 · Android

[下载 Nice 视频 Android 1.3.10 安装包](./NiceVideos-Mobile.apk)

Android 1.3.10（22）适用于 Android 8.0 及以上手机和平板，参照同版本 iOS 的文件管理与 VR 播放功能。安装后打开「Nice 视频」。

- **从服务器下载影片**　进入「服务器」，设置 Nice 服务器地址，点影片旁的「下载」。
- **用视频链接下载**　进入「本地 → 视频直链」，粘贴可直接访问视频文件的 HTTP 或 HTTPS 地址，点「开始下载」。可填写希望在文件管理器中显示的文件名。链接可以带签名参数，网页、登录页和 HLS／DASH 播放列表不适用。
- **查找已经下载的视频**　在系统文件管理器打开「内部存储 → Download → NiceVideos」。完成的影片也出现在 App 的「本地」。在文件管理器移走文件后，可在服务器列表重新下载，或在本地页清理已删除文件的记录。
- **将本机视频上传到服务器**　在「服务器」设置地址后，点「上传本机视频」，用系统文件选择器挑选一部或多部影片。
- **在平板上看 VR**　在「VR」打开文件或添加文件夹，可按片源选择 180°、360°、左右分屏或上下分屏。

此版使用独立的应用标识，可以与早期试用版并存。已放在公共目录的影片可以从系统文件选择器打开，旧 App 私有目录里的历史下载仍由旧 App 管理。

## 在手机上试播 VR

1. 打开「VR → 添加文件夹」，选择影片所在的公共子目录，例如 `Download/NiceVideos`。在系统中点「使用此文件夹」，回到 App 后点影片即可播放。也可以点「VR → 打开影片」直接选择一部。视频从所选位置读取。
2. 对于 `vr360-8k-sbs-8s-hevc.mp4` 这类明确带有 360 标记的文件，首次从 VR 入口打开会选用 360° 全景。普通文件默认 180° 左右分屏。可在「VR 设置」修改投影和片源排布，已保存的手动选择优先。手持手机／平板选「单屏观看」，放进手机眼镜时点「双眼眼镜」。
3. 视频播放完后，在同一页面点「重播」。播放器从零开始，重新建立解码器和视频输出。播放中如果时间持续前进而画面没有新帧，播放器会尝试一次按原进度重连。若仍有声音却没有画面，点「片源信息 → 复制诊断」，查看编码、原始分辨率、实际选择的解码器、GL 纹理上限和本次视频输出帧数。
4. 8192 × 2048、24 fps 的左右分屏文件需要设备支持这个完整尺寸、帧率和编码配置。降低 VR 渲染清晰度会减少屏幕绘制开销，设备仍需要解码完整视频轨。

## 先导出到手机公共存储

**已经安装仓库的 1.2.0，有旧下载时请先保留它。** 在 Mac 上连接手机或平板，授权 USB 调试，确认已安装 Python 3.8+ 和 Android 平台工具（`adb devices` 显示设备状态为 `device`）。在本分支仓库根目录运行：

```sh
python3 android/tools/legacy_download_backup.py export
```

工具直接在手机上复制已完成的下载，并核对副本大小和 SHA-256。看到 `Verified export complete` 后，在「文件管理 → 内部存储 → Download → NiceVideos」按片名打开。再次执行会复用内容相同的同名文件，遇到同名不同内容会给新文件加编号。原 App 里的视频、收藏和进度保留；导出文件仅包含影片本身。若设备拒绝 USB 读取旧目录，工具会停止，请继续保留旧版。

**已安装 1.2.2 或更新版本时**，进入「本地」，点影片右边「⋮ → 导出到文件夹」，或点「导出全部」。在系统选择器中选择或新建一个公共子文件夹，例如 `Movies/NiceVideos`，再点「使用此文件夹」。Android 11 及以上可在 `Download` 内选择一个子文件夹。导出只复制下载完成的影片，同名且内容相同的文件会复用。原片和播放记录保留。如果已经安装 1.2.1，已下载到 `Download/NiceVideos/` 的影片可以直接通过文件管理器复制。无需为了导出这些公共影片卸载 1.2.1；卸载会清除它的片库和进度。

## 安装试用

将 `NiceVideos.apk` 传到设备，在系统文件管理器中点开安装。如果系统询问是否允许本次来源安装应用，可给打开 APK 的文件管理器授权。已连接 USB 调试的 Mac 也可在仓库根目录执行：

```sh
adb install -r android/NiceVideos.apk
```

### 从 1.2.0 升级并保留历史视频

同一证书签名的自建版本可直接覆盖安装。仓库分发的 APK 由 CI 使用临时调试证书签名，旧版分发包和新构建可能签名不同。已有仓库旧版时，可以直接安装上面的并存版使用公共目录影片。遇到 `INSTALL_FAILED_UPDATE_INCOMPATIBLE` 或「签名不一致」，保留旧应用，先备份视频。卸载会清理旧版专属目录。

从仓库的 1.2.0 调试包换到不同签名的新版时，可以用 Mac、Python 3.8+ 和 Android 平台工具中的 `adb` 保留离线影片、收藏、服务器配置和续播进度。连接平板并授权 USB 调试，在旧版中等下载结束或取消未完成的下载。用以下命令将副本备份到 Mac 上空间充足的新文件夹。旧视频目录的 USB 访问能力取决于设备系统。若提示无法读取目录、发现影片缺失或校验失败，请保留旧应用和它的数据；这种情况下还没有可用于换包的完整备份。示例命令在仓库根目录运行。

```sh
python3 android/tools/legacy_download_backup.py backup "$HOME/NiceVideos-1.2-backup"
```

看到 `Verified backup complete` 后，核对影片数量和备份中的 `manifest.json`。有下载记录却显示 0 个文件时，请保留旧安装并检查当前设备和用户。确认备份完整后，可在设备上卸载旧版、安装此版，再运行下面的命令。请在恢复完成后再添加新影片。

```sh
python3 android/tools/legacy_download_backup.py restore "$HOME/NiceVideos-1.2-backup"
```

看到 `Verified restore complete` 后打开 App 的「本地」。旧版中通过「打开文件」选过的外部影片仍在原处；更换安装后，Android 可能需要重新授权那些文件。请保留 Mac 上的备份直到在文件管理器和 App 内确认影片可播放。

### 下载位置与历史迁移

新下载保存在内部存储的 `Download/NiceVideos/`。可用文件管理器按片名查找，同名文件会使用新的文件名。Android 8、9 首次向公共目录写入时需要授予存储权限。

1.2.2 覆盖升级后，旧版下载会留在原处，可以先导出副本。要将原片移到公共目录，在「本地 → 迁移历史下载」中确认「开始迁移」。之前已经开始的迁移会继续，使用备份工具恢复的影片会按恢复流程自动迁移。迁移保留片库编号、收藏及续播位置。覆盖升级时仍在传输的任务可在完成后迁移，失败任务再次下载时使用公共目录。迁移会先核对公共副本，再清理旧文件。设备不支持直接链接时，需要为当前影片留出复制空间。中断后可重新打开 App 继续，或点「本地 → 迁移历史下载」重试。

在已下载影片右侧菜单中，「从列表移除」保留公共文件，「删除本机副本」会删除公共文件。

## 播放

- 在首页点「打开文件」，用 Android 系统文件选择器选视频。播放器直接使用提供方交给它的 URI，无需将手机或平板上已有的视频导入片库。网盘提供方可能会先下载或缓存文件。拖动进度需要提供方支持随机读取。
- 打开影片后先显示原始画面，点底部「VR」进入。首次默认按 180° 全景、左右分屏、单屏观看处理，适合在平板上直接拖动环顾。点「VR 设置」按原片指定投影、片源排布和观看方式，设置按文件保留。
- 左右两幅为经纬全景图时选「180° 全景」或「360° 全景」；左右各有一个圆形鱼眼图像时可试「180° 鱼眼」（等距圆形，图像居中）；普通左右 3D 影片选「平面影院」里的半宽／全宽 SBS。全景同时支持单画面、左右和上下排布。180° 片源在后半球没有影像。
- 平板直接看选「单屏观看」，横放进手机眼镜选「双眼眼镜」。全景下单指拖动环顾、双指缩放、默认双击或点「回正」恢复正面。在「VR 设置」可以把「画面双击」改为播放／暂停、显示／隐藏控件，或把「双指缩放幅度」设为精细、标准或快速。这些手势偏好对各部影片生效。陀螺仪跟随可手动打开，依赖设备旋转传感器。切换观看方式和投影沿用同一播放进度和解码器。
- 高分辨率屏幕进入 VR 时默认用「流畅（最长边 1920）」绘制最终画面，保持屏幕比例。需要看清细节时可在「VR 设置 → VR 渲染清晰度」切换「屏幕原生」。该选项只控制 VR 画面绘制，播放器继续直接读取和解码原文件。
- 在 VR 播放画面中，Android 手柄 A 键切换播放／暂停，X 键回正全景视角，Y 键显示／隐藏控件，L1 后退 15 秒，R1 快进 15 秒。音量键保留系统行为。
- 拖动画面时可继续听当前声音。拖动底部进度条会预览时间，松开时跳一次，系统取消手势时继续原位置。需要排查断音时，可查看「片源信息」里的本次音频缓冲耗尽次数。
- 「片源信息」显示可读取的分辨率、编码、帧率和解码器名称。播放时会监测进入 GL 绘制的不同视频帧，重连后仍然停帧会提示检查解码。遇到有声无图或解码失败，可在「片源信息」尝试设备提供的软件解码。设备缺少适用的软件解码器时，点「恢复自动解码」即可回到原进度。原文件的码率、分辨率和帧率决定解码负载。播放器支持超过 4 GiB 的文件偏移。
- 本地列表可按收藏或已下载筛选。文件菜单可以收藏影片、移除最近记录或删除已下载副本。
- 服务器页可填写本仓库 `videos/` 服务的地址，例如 `http://192.168.1.20:8106`，从列表下载到本机后离线播放。连接同一 Wi-Fi 时填服务器的局域网 IP。

## 自行构建

使用 JDK 17、Android SDK Platform 35 及 Build Tools 35.0.0。Gradle Wrapper 位于本目录。

```sh
cd android
./gradlew :app:assembleDebug :app:assembleVrPreview
```

原包名版本输出为 `app/build/outputs/apk/debug/app-debug.apk`，并存版为 `app/build/outputs/apk/vrPreview/app-vrPreview.apk`。运行设备测试另需 FFmpeg、Python 3 和一台 Android 设备或模拟器。测试资源由 Gradle 生成，只放入测试包。

```sh
./gradlew :app:connectedDebugAndroidTest
```
