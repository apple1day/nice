# 本地视频与下载任务批量删除

## 使用

本地页顶部点击「选择」，点行勾选多个视频，底部「删除所选（N）」确认后立即删除手机文件。
支持全选/取消全选，顶部「完成」退出选择模式。全选只针对当前搜索结果；搜索过滤掉的项目取消选择。
选择模式点行不会播放，单行左滑删除仍保留。批量立即删除不受播放器的“三条待删除队列”数量限制。

下载任务页顶部增加「选择」和「一键清空」；选择后可以全选并批量删除。
一键清空会先确认，范围是打开确认时本页所有进行中、失败或已取消的任务。
进行中任务在索引成功删除后取消，失败记录及残留的未完成文件一同清理。
**不会删除已完成的本地视频、服务器上的文件，也不会调用服务器 DELETE 接口。**

## 边界

- 确认保存的是下载 attempt 的快照，不是确认时重新读取“全部”。新任务不会被旧确认删除。
- 确认期间完成或重新下载的任务保留；完成文件有额外的落盘检查保护。
- 系统任务恢复期间禁用下载页的批量删除和清空，避免取消未完成恢复映射的任务。
- 正在播放的文件继续受保护；同一批中其他文件可以删除，失败项目保留并汇总提示。
- 使用现有可恢复删除事务：先暂存文件，再提交索引，最后回收空间。写入失败还原文件。
- 成功删除后同步清理进度、播放书签、待删除队列成员。迟到的旧任务回调无法恢复被删记录。
- 本次不修改播放器控制、左右切换、服务器 API、Bundle Identifier 或下载索引格式。
- 多文件删除逐项提交，并非全批次原子事务；部分失败会明确显示，不能误报全部成功。

git fetch origin
