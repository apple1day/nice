# v1.2_batch_delete：本地视频与下载任务批量删除

在 v1.1_watch_delete 的播放、滑动切换、待删除队列和删除恢复事务之上增加；本次不修改 Go 后端、播放器内核、Bundle Identifier 或已有数据格式。

## 操作

**本地视频**：顶部「选择」→ 勾选多个视频（点击行不会播放）→ 底部「删除已选（数量）」→ 确认。支持全选/取消全选、取消选择；搜索后只保留当前可见结果的勾选，不会删除隐藏选择。原单项左滑删除保留，并统一走确认流程。多选模式下暂时收起旧的待删除队列操作区，退出后恢复。

**下载任务**：顶部「选择」→ 多选 → 底部删除；顶部另有「一键清空」。两种删除都需要确认。一键清空作用于打开确认框时的未完成任务快照，不要求先全选，不会把后来新建的任务扩大进删除范围。

- 本地视频删除：立即移除所选手机文件、播放进度和待删除队列标记；不影响服务器原视频。
- 下载任务删除/清空：取消仍在下载的任务，移除失败/取消记录以及残留文件；保留已经完成的本地视频，不调用服务器删除接口。
- 下载在确认期间刚完成：跳过，不删除刚完成的视频。
- 下载在确认期间被重试：通过 `taskToken`（ID + attempt）识别，旧快照不删除新的下载批次。
- 已经移除的项目：跳过。重复确认不会删除其他项目。
- 正在播放、文件操作失败、索引落盘失败：保留该项，继续处理其他所选项；给出成功/跳过/失败数量，失败项可重试。
- 系统下载任务恢复期间：暂时禁止删除操作，避免在任务关联恢复前清理记录却漏取消系统任务。
- 删除成功仍复用原 `removeFromDevice` 事务：保存索引后取消系统任务、清理进度和播放位置，延迟回调无法重新创建已删记录。空间回收警告保留在「查看处理结果」中。

这里的「删除已选」是立即删除，不是把视频批量加入最多 3 项的待删除队列。旧队列功能仍保留。

## 文件

- `NiceVideos/BatchSelection.swift`：可见行选择状态，按下载批次隔离。
- `NiceVideos/BatchDeletion.swift`：确认快照、删除范围复核、结果汇总；复用原存储事务。
- `NiceVideos/BatchDeletionViews.swift`：本地列表、下载任务页及共用的选择/确认/结果展示。
- `NiceVideos/Views.swift`：保留根页面、服务器页面、设置页面；本地及下载页面移入新文件。
- `Tests/BatchDeletionTests.swift`：13 项选择/批量删除回归测试。
- `check-batch-delete.sh`：10 项可独立运行的 Swift 选择状态检查。

## 拉取后运行

在仓库根目录执行：

```bash
git fetch origin
git switch v1.2_batch_delete
git pull --ff-only origin v1.2_batch_delete
cd ios
bash setup.sh
open NiceVideos.xcworkspace
```

必须重新生成工程，使新增 Swift 文件加入 target；沿用现有 `setup.sh`，保留 CocoaPods 和签名配置处理。不要卸载旧 App，不要改 Bundle Identifier，以免丢失本地下载。

CI 增加仅针对 `v1.2_batch_delete` 的 push 触发，保留原 PR/手动触发及其余测试步骤。

真机验收：搜索后全选删除只影响可见文件；取消确认不删除；选中行不触发播放；同时存在本地视频、进行中和失败任务时清空下载页，确认本地视频仍可播放；正在下载的任务被删除后不再传输/重新出现；空列表按钮禁用；横屏及大字号下按钮可见；重启 App 后删除结果仍正确。
