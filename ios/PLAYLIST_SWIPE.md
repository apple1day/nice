# 本地播放列表、上下滑切换与底部删除

## 操作

打开任意已下载视频时，按未过滤的「本地视频」列表顺序建立本次播放列表，从点击的那条开始。
播放列表来自手机本地已完成下载，不依赖服务器、登录或网络；搜索只影响列表查找，不会缩小本次播放列表。

当前方向采用常见短视频交互：**上滑播放下一个，下滑播放上一个**。

- 拖动过程中当前画面跟随手指移动，相邻页面同步进入。
- 快速甩动会结合系统预测终点决定是否翻页。
- 未达到切换阈值时弹回当前视频。
- 第一条向下滑、最后一条向上滑时使用阻尼回弹，不循环播放。
- 水平拖动、轻微抖动和进度条操作不会切换视频。
- 横屏底部仍可直接使用「上一个 / 下一个」按钮。

底部「播放列表 / 序号」按钮可展开全部本地条目并点选切换；VoiceOver 也保留上一条/下一条操作。

## 播放控制

竖屏控制保持紧凑布局：

```text
后退15秒 | 播放/暂停 | 删除 | 前进15秒 | 全屏/退出全屏
```

横屏增加上一条和下一条：

```text
上一个 | 后退15秒 | 播放/暂停 | 删除 | 前进15秒 | 下一个 | 全屏/退出全屏
```

保留全屏和无操作自动隐藏。拖动进度、上下翻页、播放列表弹出、暂停和错误状态下不会自动隐藏；切换视频后不退出全屏。

## 待删除逻辑

播放器里的「删除」按钮**只把当前视频加入待删除列表，不会立即删除文件**。

- 待删除数量没有上限。
- 不再有「最多 3 个」限制。
- 不再自动删除最早的视频。
- 真正删除只能回到本地视频列表顶部，点击「一键删除待删除视频」并再次确认。
- 列表中的待删除项目可以单独撤销。
- 正在播放的视频在真正删除时会被保护，关闭播放器后可再次执行一键删除。
- 删除手机副本不会删除服务器文件。

## 更新

保存并关闭 Xcode 后，在仓库根目录执行：

```bash
git fetch origin &&
git switch v1.2_batch_delete &&
git pull --ff-only origin v1.2_batch_delete &&
cd ios &&
bash setup.sh &&
open NiceVideos.xcworkspace
```

保持原 Bundle Identifier 和签名 Team，不要卸载旧 App，以免删除已有本地视频。

## 验证

```bash
bash ios/check-playlist.sh
bash ios/test.sh
```

真机重点验证：从列表中间打开视频，上滑应进入下一条，下滑应返回上一条；慢拖应跟手，快速甩动应能切换，短距离拖动应回弹；第一条下滑和最后一条上滑应阻尼回弹；横向拖动和进度条操作不得误切视频。
